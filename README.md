# Diffusion Models

This repository contains implementations of DiT with a docker image

## Pull Docker Image
From Jourdan's Docker Hub

```bash
docker pull azeroman7/dit-image:v1.0
```

## Inside a Docker, run this:
```bash
docker run --gpus all -it azeroman7/dit-image:v1.0
conda activate DiT
./run_sh
```
